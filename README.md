# awesome-open-source-alternatives
> Open-source alternatives to paid software. Curated, simple, and free to use — one line per entry.
- [AppFlowy](https://appflowy.com/) — Open-source workspace, Notion-style
- [AFFiNE](https://affine.pro/) — Docs, whiteboards and databases in one app
- [GIMP](https://www.gimp.org/) — Full photo editor, free forever
- [Krita](https://krita.org/) — Painting and illustration, loved by artists
- [Photopea](https://www.photopea.com/) — Photoshop in the browser
- [Mattermost](https://mattermost.com/) — Team chat you can self-host
- [Jitsi Meet](https://meet.jit.si/) — Video calls with no account needed
